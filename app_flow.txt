## 2. Primary User Flow — District Officer

```
1. Open app → Landing page
   Visual: "EVACUATE SMARTER." headline, animated heatmap preview
   Action: clicks "View Live Heatmap"

2. National Heatmap loads
   Visual: India choropleth — Uttarakhand glows red
   Action: officer clicks Uttarakhand

3. State Dashboard — Uttarakhand
   Visual: District list, Rudraprayag shows EXTREME badge, score 0.87
   Action: clicks Rudraprayag

4. District Dashboard — Rudraprayag
   Visual: Score card (0.87 / EXTREME), rainfall 78 mm, slope 2.3°
   No action needed — data is immediately scannable

5. Evacuation Matrix

   Action: clicks Kalimath row → map highlights route

6. Route Map
   Visual: Red pin at Kalimath, green pin at GHS Block 4, route polyline
   Action: satisfied; moves to alert

7. Alert Simulator
   Action: clicks "Generate Alert"
   Visual: SMS text appears in phone-frame mockup
   Action: clicks "Copy" — ready to dispatch
```

## 4. Alert State Machine

```
[Idle]
  │
  ├─ rainfall data received ──→ [Computing]
  │
[Computing]
  ├─ score < 0.25  ──→ [Safe]       no alert shown
  ├─ score 0.25–0.5 ─→ [Watch]      yellow info banner
  ├─ score 0.5–0.75 ─→ [Standby]    orange alert panel opens
  └─ score > 0.75  ──→ [Extreme]    pulsing red banner + auto-populate SMS
                                     ↓
[Any alert state]
  ├─ user clicks dismiss ──→ [Acknowledged]  banner collapses
  └─ 24 h passes          ──→ [Idle]
```

## 6. Navigation & Routing

**Router:** React Router v6 (`createBrowserRouter`)

**Back navigation:** Each page has a breadcrumb: `National → Uttarakhand → Rudraprayag`

**Deep-link support:** `/district/rudraprayag` loads directly without needing prior navigation (data fetched on mount via district ID)

**Loading states:** Skeleton placeholders on RiskScoreCard and EvacuationMatrix while API responds

**Error states:** If API fails, fall back to mock data silently (no error screen — demo must not break)

## Phase 1 — Risk Engine + Mock Data (Hour 1–4)

**Goal:** `/api/risk-scores` returns believable data. Risk formula runs.

**Backend tasks:**

1. Create `server/engine/risk.py`:
```python
def compute_risk(rainfall_mm, slope_deg, basin_area_km2, drainage_cap):
    rainfall_factor = min(rainfall_mm / 50.0, 2.0)
    terrain_factor  = 1.0 / (slope_deg + 0.1)
    drainage_factor = basin_area_km2 / max(drainage_cap, 1)
    score = min((rainfall_factor * terrain_factor * drainage_factor) / 10.0, 1.0)
    tier = "Extreme" if score > 0.75 else "High" if score > 0.5 else "Moderate" if score > 0.25 else "Low"
    return round(score, 2), tier
```

2. Create `client/src/data/mock-districts.json` — 5 states, 3 districts each, pre-scored.

3. Create `server/routes/riskScores.js` — reads mock JSON, returns array.

4. Unit-test formula:
   - Kedarnath (high rainfall, low slope): should be Extreme
   - Rajasthan desert (low rainfall): should be Low

**Deliverable:** `GET /api/risk-scores?state=UK` returns valid JSON with at least 3 districts.

## Phase 4 — Alert Simulator (Hour 13–16)

**Goal:** Generate SMS alert text, display in phone-frame mockup, copy to clipboard.

```jsx
function AlertSimulator({ district, tier, safeZone }) {
  const [alertText, setAlertText] = useState('')

  const generate = async () => {
    const res = await axios.post('/api/alert-generate', { district, tier, safeZone })
    setAlertText(res.data.alertText)
  }

  return (
    <div>
      <button onClick={generate}>Generate Alert</button>
      {alertText && (
        <div className="font-mono text-sm bg-gray-900 rounded-xl p-4 mt-4">
          <pre>{alertText}</pre>
          <button onClick={() => navigator.clipboard.writeText(alertText)}>
            Copy
          </button>
        </div>
      )}
    </div>
  )
}
```

**Deliverable:** Alert generates, displays, copies to clipboard.
